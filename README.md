# Guías de Matemáticas

Colección de guías de repaso para cursos de matemáticas, basadas en los textos clásicos de Larson, Purcell, Zill y Leithold.

## Contenido

| Curso | Descripción | Referencia |
|-------|-------------|------------|
| [Álgebra Lineal](./algebra-lineal/) | Álgebra de matrices, sistemas de ecuaciones, ajuste de curvas y Cayley-Hamilton | Larson (8.ª ed.) |
| [Cálculo Diferencial](./calculo-diferencial/) | Límites, continuidad y técnicas de derivación | Larson (6ª ed.) / Leithold (7.ª ed.) |
| [Cálculo Integral](./integral/) | Fundamentos de la integral y métodos de sustitución | Purcell (9.ª ed.) |
| [Ecuaciones Diferenciales](./ecuaciones-diferenciales/) | Métodos analíticos para ecuaciones de primer orden | Zill (3.ª ed.) |
